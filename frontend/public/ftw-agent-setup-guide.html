Client setup guide

Connect your FT Williams computer

Four simple steps. Your FT Williams password and browser session stay on your computer.

  1. Download and open the FT Williams Agent

    Use Download FTW Agent in ERISAPros, then double-click the setup file. Windows may show “Unknown publisher” for the pilot build.

  2. Enter your one-time connection code

    In ERISAPros, open FTW Agent, choose Connect this computer, and enter the code in the installer. The code expires after 10 minutes and works once.

  3. Sign in to FT Williams once

    The agent opens a dedicated FT Williams browser. Complete the normal login and any MFA prompt yourself.

  4. Test connection

    Return to FTW Agent in ERISAPros and click Test connection. You should see “Connection test passed.”

Done — leave the agent running. Approved work for your workspace can now use this computer.

If you see “Login required”

Sign in in the dedicated FT Williams window. Waiting work pauses safely and resumes automatically on the next agent check.

If the browser was closed

The agent reopens the same dedicated profile. If FT Williams has ended the session, sign in again and click Test connection.

If the computer is offline

Reconnect to the internet and start the FT Williams Agent. No filing is sent while the agent is unavailable.

If the wrong account appears

Stop and contact your ERISAPros administrator. The agent will not process work for a different FT Williams account.

Safety: ERISAPros does not store or type your FT Williams password. Pairing is private to your workspace, and the agent verifies the account and filing target before any approved action.
Need help? Contact your ERISAPros administrator. Never send a pairing code, password, or MFA code by email or chat.
