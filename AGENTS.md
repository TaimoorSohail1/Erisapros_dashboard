## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for this repository. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical triage-role labels plus `priority:p0`–`priority:p3` and `status:*` workflow labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository: use root `CONTEXT.md` when present and system-wide ADRs under `docs/adr/`. See `docs/agents/domain.md`.
