# Domain docs

This repository uses a single domain context.

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read relevant system-wide decisions under `docs/adr/` when that directory exists.
- If either is absent, proceed without treating the absence as a blocker.

## Vocabulary

Use domain terms exactly as defined in `CONTEXT.md`. If a required term is missing, record the gap rather than silently inventing a conflicting synonym.

## Architecture decisions

Surface any conflict with an existing ADR explicitly. Do not silently override a recorded architectural decision.
