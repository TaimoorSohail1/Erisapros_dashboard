# Triage labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

## Priority

- `priority:p0`: critical production blocker
- `priority:p1`: high priority
- `priority:p2`: normal priority
- `priority:p3`: low priority

## Workflow status

- `status:ready`
- `status:in-progress`
- `status:blocked`
- `status:review`
- `status:done`
