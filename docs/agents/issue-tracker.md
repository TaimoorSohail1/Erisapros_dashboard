# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI for all operations and infer the repository from the configured GitHub remote.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List work with `gh issue list`, filtering by state and labels as needed.
- Comment with `gh issue comment <number> --body "..."`.
- Apply or remove labels with `gh issue edit`.
- Close completed work with `gh issue close <number> --comment "..."`.

When an engineering skill says to publish work to the issue tracker, create or update a GitHub issue in this repository.
